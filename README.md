# Enterprise Plugin

This plugin demonstrates the use of commands, agents, skills, hooks and MCP servers for Claude Code.  The plugin structure follows the recommended layout and includes example files for each component.

- Commands are stored in the `commands/` directory.
- Agents are stored in the `agents/` directory.
- Skills live under `skills/` as folders containing `SKILL.md`.
- Hooks configuration is in `hooks/hooks.json`.
- MCP server definitions are in `.mcp.json`.
- Support scripts are in `scripts/`.

See the included `plugin.json` and `hooks.json` for details on how these components are configured.
